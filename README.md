# 山河無名・官方世界聖經

> 世界不以任何玩家為中心，但世界會記得每一個玩家。

《山河無名》是一款單一正史、持續運作、沒有固定主線的文字型多人武俠人生模擬遊戲。

## 公開網站

https://monoian.github.io/shanhe-wuming-world-bible/

## 目前內容

- 8 大分冊
- 116 個正式設計章節
- 世界觀、大曜王朝與九大區域
- 玩家人生、NPC 記憶與八維關係
- 世界時間、事件總帳與因果引擎
- 武學、戰鬥、傷勢、醫療與傳承
- 經濟、法律、案件、供應鏈與玩家組織
- AI 行動解析、NPC 對話、敘事與資料邊界
- 臨川府、春水藥案與完整開發藍圖

## 部署

網站由 `.github/workflows/pages.yml` 自動部署至 GitHub Pages。`site.html.gz` 是完整網站來源的壓縮版本，工作流程會將它解壓縮為正式的 `index.html` 後發布。
